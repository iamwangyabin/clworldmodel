# CNN Mechanism-Bank ARROW v1 (Atari)

## Scope

`CNN-MechanismBank-RSSM-ARROW-v1-Task1SnapshotSeeded-Atari-TaskAware`
is a single-seed pilot protocol for separating stable expansion over a frozen
world-model core from learned reuse of older nonlinear mechanisms. It is not a
task-agnostic protocol and a pilot result is not a reproduced paper claim.

The three-task order is MsPacman, Boxing, and CrazyClimber, with 90 epochs per
task. Task 1 comes from the fixed strong boundary snapshot. Later tasks share
its frozen CNN and base RSSM, and own a spatial projector, recurrent/posterior/
prior residual mechanisms, private observation/reward/continue heads, and a
fresh Actor-Critic. The complete architectural decision and parameter budget
are recorded in `docs/decisions/0036-cnn-rssm-mechanism-bank.md`.

## Matched Reuse Ablation

The primary route applies each frozen older mechanism through an independent
zero-initialized `tanh` scalar. The `NoReuse` arm allocates the same mechanism
and route tensors but leaves every reuse gate frozen at zero. All other
resolved configuration fields must match. Identical seeds mean matched random
streams; realized online trajectories are not claimed to remain identical once
the deterministic policies diverge.

Compare Task-3 reuse and NoReuse using:

- final held-out raw return from the fixed 16-rollout cohort;
- periodic-validation AUC over completed epochs 180 through 270;
- first completed epoch whose fixed-cohort mean reaches raw return 50,000; and
- best periodic-validation raw return and its snapshot SHA-256.

## Post-Hoc Gate Ablation

`scripts/evaluate_cnn_mechanism_bank_reuse.py` evaluates the same epoch-270
world model and Task-3 Actor-Critic under five transient in-memory conditions:

1. learned full reuse;
2. all reuse gates zero;
3. recurrent reuse zero;
4. posterior reuse zero; and
5. prior reuse zero.

Every condition uses the same held-out base seed, 16 deterministic rollouts,
latent modes, and policy argmax. The script restores the original gate logits
after each condition and verifies a digest over every world-model tensor before
and after evaluation. It performs no gradient update and never writes
evaluation transitions to Replay.

For mechanism family `m`, functional reuse is reported as

```text
eta_m = mean(||g_m M_old(x)||_2) / mean(||M_new(x)||_2).
```

The means use a shared fixed-decision trajectory generated by the full-reuse
policy on the held-out seed. On that same trajectory, the diagnostic reports
posterior `KL(full || ablated)`, categorical prior Jensen-Shannon divergence,
observed hidden-state drift, reward-prediction drift in raw reward units, and
15-step imagined hidden/reward drift. Imagined comparisons apply the full
policy's action sequence to both routes, isolating world-model route effects.

This post-hoc test measures dependence of the already-trained policy. It does
not replace the matched NoReuse retraining arm.

## Cross-Cohort Check

The evaluator completes this two-by-two table for CrazyClimber:

| Snapshot | Fixed periodic cohort | Fixed held-out cohort |
| --- | ---: | ---: |
| completed epoch 260 | saved metric | reevaluated |
| completed epoch 270 | reevaluated | saved metric |

The full-reuse held-out reevaluation at epoch 270 must reproduce the saved
16-rollout mean within absolute tolerance `1e-3`. This separates late learning
from cohort difficulty without selecting favorable seeds.

## Artifact Contract

Actual evaluation requires a clean pushed commit with `ahead=0` and `behind=0`.
The output directory is unique and contains a manifest, results, result
SHA-256, and terminal run status. Source snapshot paths and SHA-256 values,
cohort seeds, budgets, condition routes, metric definitions, and limitations
are persisted. Source snapshots remain inference-only and non-resumable.
