# Frozen CoinRun task-ID prefix classifiers — pilot v1

Protocol: `CoinRun-Frozen-TaskID-PrefixClassifier-Pilot-v1`.
Entrypoint: `scripts/eval_coinrun_temporal_task_id.py`.

## Question and invariant

Does a learned causal correction of the first-frame reconstruction scores
improve **true task-ID accuracy** as observations accumulate? This is a new
supervised-router variant, not a redefinition of the parameter-free D-AutoRoute
baseline. Neither task discovery nor within-episode task changes are studied.
There is no switching penalty, stop threshold, hysteresis or reward objective.
All classifiers predict every prefix, even if their previous prediction differs.

The historical boundary-270 D-AutoRoute inference checkpoint is frozen. Its
three acquired routes are CoinRun, CoinRun+NB and CoinRun+NB+RT (restrict themes).
These are visual variants; no distinct-dynamics claim is made. Do not revive
retired algorithms from the historical source just because its snapshot loader
imports retained-method construction from an older shared launcher.

## Data isolation and environment budget

Fresh episode-seed groups, paired across task variants, are assigned to exactly
one of training (256/task), validation (128/task), and test (512/task). No
earlier routing evaluation trajectories are used to fit or select this model.
Root seed 20260909 and split domains 6101/6201/6301 determine the saved seed plan;
actual within-split seeds are generated by the existing diagnostic collector.
All 896 environment seeds must be unique across splits. Frame-level random
splits are forbidden. Distinct generator seeds are not a guarantee that rendered
images or level layouts are globally unique.

With three routes: 768 train, 384 validation and 1,536 test episode prefixes,
at most 16 actual decisions and 17 observations each, totaling at most 43,008
agent decisions. Episodes ending early stay in the data; their native autoreset
frame is excluded. Raw rewards are preserved but never used by a classifier.
Environment options, action semantics, preprocessing and termination handling
are inherited unchanged from the saved CoinRun configuration/adapter.

All trajectories use the existing deterministic first-frame route and its
private Actor for behavior. True IDs never enter the behavior policy or the
candidate scoring function. Thus this measures classification on **matched
first-frame-policy trajectories**, not closed-loop consequences of rerouting.
There are zero WM updates, AC updates or Replay writes.

Training labels supervise only the new router. Validation labels select its
epoch, without gradient updates. Test environments are not created until all
router snapshots and their state digests are sealed. Test features/labels cannot
affect normalization, temperature, epochs, weights or any stopping rule.

## Shared features and classifiers

Every candidate RSSM filters the same actual observation/action sequence with
its own state, using deterministic posterior modes and its existing decoder.
The FP32 pixel-MSE vector `e[t,k]` is a discriminative feature, **not a predictive
likelihood**. No prior/dynamics/KL signal is used. The optional reconstruction-only
path reuses the prior diagnostic scorer; its default behavior is unchanged.
The exact first-frame production scores are retained: batching may change BF16
rounding, so batched first scores are audited and then replaced by those actually
used by the behavior router. All arms receive the same resulting feature array.

Fit mean/std on valid **training** error vectors. Fit one shared positive
temperature T0 on training first-frame NLL using the fixed 61-point grid
10**linspace(-6,0,61). It cannot change first-frame argmin. Scores are not claimed
to be calibrated probabilities on test data.

Comparisons:

1. **first_frame_mse**: original first-frame argmin at every prefix.
2. **mean_prefix_mse**: mean reconstruction MSE over all available prefix frames.
3. **pointwise_mlp**: two ReLU layers of width 56 on the normalized current error
   vector; output logits `-e[t]/T0 + MLP(e[t])`. No explicit temporal aggregation.
   Since RSSM errors themselves depend on history, this is not an RGB-only
   memoryless classifier. Its first-frame prediction, held constant, is also
   reported as **learned_first_frame_mlp**, without training an additional model.
4. **temporal_gru**: one causal GRU layer of width 32 and linear K-output head.
   With r[t] = GRU(r[t-1], normalized e[t]), output
   `-e[0]/T0 + W*r[t]+b` for t>=1. At t=0 the correction is exactly zero, so
   initial decisions match the original router. The correction is cumulative
   over the whole prefix, **not** added again to the previous posterior/logits.

Output layers start at zero. K=3 yields 3,587 MLP and 3,651 GRU parameters;
report the actual counts. Both use every valid training prefix with equal
episode weight, then equal prefix weight inside each episode. GRU t=0 loss is
constant, while the MLP can learn its first-frame prediction; this difference
is explicit, not an exact equality of their effective gradient budgets.

Both heads use AdamW, LR 0.003, weight decay 0.0001, gradient norm limit 5,
batch 64 episodes, 100 epochs. Three predeclared router seeds come from domain
6401; shuffles use owned generators in domain 6501 and are matched across heads.
Each head receives 1,200 updates: six models, 7,200 router-only updates total.
Router optimization is CPU float32; world-model feature extraction uses the
recorded CUDA/BF16 runtime. This is three router initialization seeds on **one**
world-model checkpoint, not three independently trained world-model seeds.

Select each head's epoch using highest validation mean per-episode accuracy
across all available post-first-frame prefixes; break ties by lowest prefix
NLL, then earliest epoch. No test-driven window or seed selection. Persist full
epoch histories and inference-only snapshots; they are not resumable training
checkpoints. No new resumable-training claim is made.

## Reporting

Save every test-prefix logit, prediction and validity mask. Report all prefix
lengths 1..17, with headline columns 1/2/5/9/17 fixed before opening test data.
Primary curves retain all 1,536 test episodes: at a frame budget beyond an
episode's end, carry forward its **last real** prediction, without feeding padded
frames. Also report exact-prefix-only accuracies and their changing sample
counts; do not silently compare selected survivors to full-cohort first frames.

Each router seed's task confusion, accuracy and first-frame corrected/broken
counts are retained. Learned headline entries are the average accuracy over the
three training seeds, not an ensemble. Raw rewards are not classification
metrics. Decreasing entropy is neither an objective nor evidence of accuracy.

The versioned `report()` function generates SUMMARY.md from results.json without
additional interaction or optimization. A pilot on one frozen checkpoint cannot
establish general high accuracy, complete-six-task identification, or behavior
performance under repeated switches.

## Launch and checks

Every collection and router-optimization command must run from a clean, pushed,
upstream-synchronized commit with a fresh fetch receipt. GPU transfer may use
the existing checksum-verified Git bundle plus controller fetch receipt. Save
config, seed plan, model digests, dependencies, hardware, exact budgets, training
selection records, raw trajectories/features, and failures. Hash WM/Actor state
before and after, and router states before and after test.

Fixed-input tests (no simulator or optimizer steps):

```bash
PYTHONPATH=src:scripts:tests python -m unittest test_coinrun_temporal_task_id \
  test_coinrun_sequence_routing_probe test_coinrun_prefix_refinement
```

Tests cover causal prefixes, exact first-frame preservation, current-step MLP
invariance, train-only normalization, seed separation, masked/equal-episode
loss, terminal cohort accounting, scorer parity and inference snapshots.
