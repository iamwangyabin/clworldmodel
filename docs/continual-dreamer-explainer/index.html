Continual Model-Based Reinforcement Learning · Research Discussion

持续 Dreamer：
问题、基线与研究路线

从 ARROW 的经验回放出发，重新审视世界模型预测目标与 Actor-Critic 控制目标在持续学习中的关系。

研究对象：Dreamer-style agent 初始基线：ARROW-50 环境：6-task continual Atari 状态：单 seed pilot 已完成

摘要

Dreamer 并非只优化一个目标。世界模型通过真实轨迹学习观测、latent dynamics、reward 与 termination； Actor-Critic 则在模型产生的想象轨迹上优化累计回报。因此，旧任务性能下降可能来自世界预测漂移、 策略技能漂移、价值估计失准或策略利用模型误差。ARROW 主要通过 FIFO 与长期记忆缓冲区维持旧数据覆盖， 但并未区分这些故障。本文档同时纳入本地已完成的单 seed ARROW-50 pilot；结果显示旧任务保持具有明显 的任务差异和非单调性，因此下一步应先做组件诊断，再决定是改 replay、Actor 巩固还是世界模型结构。

当前核心判断

现在最有价值的并不是立即提出一个 MoE 结构，而是先确定：Dreamer 的两类学习目标在持续训练中是否 产生可分离的遗忘，以及它们是否需要不同的记忆与巩固机制。

Problem formulation

问题定义

1.1 持续模型式强化学习

Agent 依次接触环境或任务 M1, …, MT。 当前阶段只能与 Mt 交互；旧环境通常不可访问， 但允许保留固定预算的 replay。目标不是当前任务分数，而是训练结束后所有已见任务的控制能力。

maxθ,φ   (1/T) Σi=1T Ji(πφ; Pi) (1)
subject to   |B| ≤ Bmax,   |Θ| ≤ K,   Cupdate ≤ Cmax (2)

其中 θ 是世界模型参数，φ 是 Actor-Critic 参数。 公平比较必须同时匹配环境交互、梯度更新、参数规模、replay 容量以及实际字节使用量。

1.2 任务困难来自哪里

困难在 continual Atari 中的表现不能混淆的因素
数据非平稳当前游戏持续占据数据流，旧游戏只通过 replay 出现采样不足与参数干扰不是一回事
世界异质画面、动力学、reward 与 termination 同时变化视觉变化不等于动力学变化
控制异质同一 18 维动作空间承载完全不同的技能Actor 遗忘不等于 world model 遗忘
尺度异质游戏回报数量级不同，critic/advantage 容易被某些任务主导人工 reward scale 会掩盖算法问题
2

Dreamer decomposition

Dreamer 的两类学习目标

2.1 世界模型：预测目标

LWM = Ldyn + Lrep + Lobs + Lrew + Lcont (3)

ARROW 的 World Model 由 Encoder、RSSM、Decoder、reward predictor 和 continue predictor 构成。 它利用已发生轨迹拟合环境生成规律。这部分本来就属于概率建模或监督/自监督预测。

  • 旧样本仍然提供有效监督信号。
  • 适合经验回放、代表样本、预测蒸馏与结构隔离。
  • 但较低的 pixel loss 不保证控制相关预测准确。

2.2 Actor-Critic：控制目标

Lactor = − E[log π(at|st) Ât] − ηH(π) (4)

Actor 在 imagined rollout 上使用 advantage 加权的 policy gradient；Critic 拟合 λ-return。 动作不是固定标签，target 会随当前 policy、critic 和 world model 一起变化。

  • 旧图片重新出现，不等于旧技能得到直接监督。
  • 适合 policy distillation、behavior cloning 或 dream rehearsal。
  • 但过强的旧策略约束可能伤害新任务 plasticity。
这里不能提前下结论。 “世界事实应该 replay、行动技能应该 rehearsal”只是待验证假设。充分的 replay 与 imagined RL 也可能恢复旧技能； 反过来，Actor 的失败也可能源自 world model 或 critic 给出的错误训练信号。

01
ARROW 不是“不遗忘”

Frostbite、Boxing 保持较强；CrazyClimber 和 Seaquest 的最后保持率明显更低，遗忘高度任务相关。

02
旧任务轨迹明显非单调

旧任务既会下降，也会在后来回升。只比较阶段结束与最终点，会漏掉恢复、波动和可能的 backward transfer。

03
训练 loss 不能解释性能曲线

World Model loss 来自 FIFO/LTDM 混合 batch，没有逐任务分解；总 loss 稳定并不能证明旧动力学仍然正确。

04
当前 run 还不能归因模块

这些曲线无法告诉我们是 Encoder/RSSM、reward head、Critic 还是 Actor 导致下降；而且本 run 未保存边界 checkpoint，后续实验必须先补上。

Component-level diagnosis

旧任务回报为什么下降

最终需要解释的是旧任务真实回报，而不是某个训练 loss。可以通过旧/新 World Model、Actor 与 Critic 的 交叉置换，把相同的性能下降分解为不同故障来源。

Fi = [JPᵢ(πi) − JP̂ₜ(πi)] + [JP̂ₜ(πi) − JP̂ₜ(πt)] + [JP̂ₜ(πt) − JPᵢ(πt)] (5)

式 (5) 是分析视角，不是 Dreamer 或 ARROW 的原始训练目标。三项分别近似描述旧技能上的模型误差、 固定模型下的策略漂移，以及当前策略对模型误差的利用。

候选故障直接测量关键干预对应方法
World Model 遗忘旧轨迹上的 latent/reward/continue error固定旧 Actor，替换旧/新 WM代表 replay、预测蒸馏、条件动力学
Actor 遗忘旧状态 policy KL、动作排名、成功率固定同一 WM，替换旧/新 Actor策略蒸馏、CLEAR、dream rehearsal
Critic 漂移value calibration、λ-return error替换 Critic 或使用 MC returnPopArt、分组 Critic、value distillation
模型利用imagined return 与 real return 差距真实短 rollout 或独立 ensemble 验证不确定度惩罚、value-aware error
6

Research hypotheses

由讨论形成的三个可证伪假设

H1

双目标遗忘具有可分离性

World Model 的旧任务预测能力与 Actor 的旧技能保留并不总是同步；单一 aggregate return 会掩盖主导故障。

反证：跨任务、跨 seed 的组件置换无法稳定地区分 WM 与 Actor 的贡献。

H2

相同 replay 并非两类目标的最优记忆

世界模型需要覆盖生成机制的证据，而 Actor 更依赖决策关键状态及其行为目标；同一轨迹可以共享，但采样价值与附加信息不同。

反证：匹配字节与更新次数后，分目标记忆不优于统一随机/ARROW replay。

H3

世界模型容量应按控制相关差异分配

若采用条件专家，路由应优先反映对 reward、value 或长期 latent rollout 的影响，而非仅根据 task ID 或 pixel similarity。

反证：value-aware routing 在匹配容量后不优于 task/context routing，或训练明显不稳定。

7.1 条件世界模型的最小结构

路由优势缺陷
Task-ID routing最清楚的 oracle，可验证专家结构是否有上限收益依赖特权标签，不能作为最终 task-agnostic 方法

Experimental design

实验路线与判别标准

Phase 0

复现 ARROW-50

冻结任务顺序、环境步数、更新次数、replay 容量和 reward scale，获得多 seed 基线与资源账单。

Phase 1

组件级交叉置换

保存每个任务边界的 WM、Actor 与 Critic；在旧任务上交叉组合，识别主导遗忘模块。

Phase 2

两类巩固独立消融

比较仅 World replay、仅 Actor rehearsal、二者组合及匹配计算量的统一 replay。

Phase 3

条件结构消融

比较 shared RSSM、oracle routing、context routing 与 value-aware routing，匹配参数和 FLOPs。

Phase 4

严格记忆压缩

在 100%、10%、1% replay 字节预算下报告结果，区分轨迹容量与实际存储。

8.1 必须报告的指标

层次主要指标目的
最终控制Raw return、final average、forgetting、BWT/FWT回答方法是否真的保留技能
世界模型latent KL、reward/continue error、multi-step rollout error定位预测机制漂移
Actor-Criticpolicy KL、action agreement、value calibration定位策略和价值漂移
结构行为router entropy、expert overlap、load balance判断 MoE 是否真正产生机制复用
资源参数、checkpoint bytes、replay bytes、FLOPs、updates排除通过更多资源取得的伪增益

8.2 决定论文故事的结果模式

WM 稳定，Actor 失效

优先研究技能记忆、dream rehearsal 与 policy consolidation。

WM 与 Actor 同时失效

双目标处理有依据；需要分别保护预测与控制。

WM 是主瓶颈

集中研究代表 replay、条件 dynamics 与 control-aware model learning。

统一 replay 已足够

双记忆假设被否定；研究重点应转向存储压缩或更困难协议。

9

Current conclusion

当前结论

  1. Dreamer 的世界模型预测目标与 Actor-Critic 控制目标必须在分析上区分，但不应未经实验就假设它们必须使用两套物理 buffer。
  2. ARROW 的核心贡献是历史覆盖；它尚未提供组件级遗忘归因，也没有针对 Actor 技能保存设计专门目标。
  3. 本地单 seed pilot 已经否定了“ARROW 对所有任务都稳定”的直觉：Boxing/Frostbite 保持较好，CrazyClimber/Seaquest 明显更脆弱。
  4. 直接加入 MoE 的故事过于传统。MoE 只能是容量分配工具，真正的研究问题是按什么信号共享或隔离，以及是否保护最终 return。
  5. 最优先的工作不是设计复杂网络，而是完成旧/新 WM、Actor、Critic 的交叉干预，建立六个 Atari 上的遗忘结构。
  6. 只有诊断表明双目标确实存在不同故障，才能合理推出“双类记忆”“Actor rehearsal”或“value-aware conditional world model”。
